# Форсайт

Лендинг агентства продвижения на Авито.

**Сайт:** https://sahland.github.io/forsite/

Статический HTML/CSS/JavaScript. Без библиотек в клиенте, внешних запросов к шрифтам,
форм сбора данных и трекеров. Контакт — Telegram или телефон.

## Локальная работа

Требуется Node.js 20 или новее. Установка пакетов не нужна.

```sh
npm run dev
```

Открыть http://127.0.0.1:4173/forsite/ .

```sh
npm run check
npm run build
```

Проверка проверяет локальные ресурсы, якоря, JSON-LD, единственный h1,
синтаксис JS и бюджет изображений. Сборка копирует только публичные файлы в `dist/`.
Имена CSS и JS включают хеш содержимого, чтобы после обновления сайт не загружал старые версии из кеша.

## Публикация

GitHub Pages настроен на GitHub Actions. Push в `main` запускает проверку,
сборку и деплой через `.github/workflows/pages.yml`.
В публикацию попадают только `index.html`, `404.html`, `robots.txt`, `sitemap.xml`,
`.nojekyll` и `assets/`. Документация и инструменты сборки не публикуются.

## Поисковые системы

- Контент присутствует в HTML без выполнения JavaScript.
- Добавлены title/description, canonical, Open Graph, Twitter card, favicon, JSON-LD
  Organization/WebSite/Service и sitemap.
- Нет запрета на индексацию главной страницы.
- На GitHub Project Pages файл `/forsite/robots.txt` не заменяет доменный
  `https://sahland.github.io/robots.txt`; его следует контролировать через корневой
  репозиторий `sahland.github.io`, если он используется. HTML robots и sitemap
  работают независимо от этого файла.
- Для ускорения обнаружения добавить сайт и sitemap в Google Search Console и
  Яндекс Вебмастер. Это требует аккаунтов владельца и подтверждения собственности;
  публикация не гарантирует сроки индексации и позиции.
- При подключении своего домена обновить canonical, og:url, ссылки JSON-LD,
  адрес sitemap, 404 и базовый путь локального сервера. Добавить CNAME в build allowlist.

Исходная страница сохранена первым Git-коммитом. Данные о проектах и ценах взяты
из неё. Стоковое фото мастерской обозначено иллюстрацией; новых результатов продаж
или отзывов в тексте нет.

Анимации — CSS и обработчик прокрутки через requestAnimationFrame. Нативная прокрутка
не перехватывается. Поддерживается prefers-reduced-motion. Диалоги нативные:
фокус удерживается внутри, Escape закрывает окно, фон становится неактивным.
